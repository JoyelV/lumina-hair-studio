# Lumina Hair Studio

Use the /skill:ui-design  skill for this project.

This is a completely new storefront. Do not reference or reuse the design direction of any other project.

Create a premium 3D e-commerce storefront for a luxury hair-care brand.

Brand category:

Premium hair repair and nourishment.

Brand personality:

- Sophisticated

- Modern

- Clean

- Premium

- Editorial

- Scientific

- Confident

Visual direction:

Luxury beauty campaign + cinematic 3D product photography.

Primary product:

Hair repair serum.

The product should be the visual hero of the website.

Design a full-screen cinematic hero with:

- realistic 3D product presentation

- soft studio lighting

- subtle reflections

- realistic shadows

- atmospheric depth

- elegant neutral environment

- restrained motion

- premium typography

- generous negative space

Do not make it look like a generic Shopify template.

Avoid:

- generic SaaS layouts

- excessive cards

- excessive gradients

- neon colors

- excessive glassmorphism

- excessive rounded containers

- flashy animations

Before implementing the complete storefront, first establish:

1. Brand visual direction

2. Color palette

3. Typography

4. Hero composition

5. 3D visual direction

6. Motion direction

7. Section structure

Show me the proposed direction first.

Do not build the entire storefront yet.
